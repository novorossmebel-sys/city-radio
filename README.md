# City Radio — «радио в мессенджере» (MVP)

Автоматизированное городское медиа для **Telegram** и **MAX**: погода, курс валют
(и далее — гороскоп, рецепты, пробки, местные новости) по расписанию «программа дня».

## Что уже работает (вертикальный срез)

- Модуль **курса валют** (ЦБ РФ, без ключей).
- Модуль **погоды** (OpenWeather, нужен бесплатный ключ).
- Публикатор **Telegram** (Bot API).
- Публикатор **MAX** — заглушка (заполним, когда подтвердим API постинга).
- Планировщик «программа дня» (APScheduler).

## Установка

```bash
cd city-radio
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env      # затем впиши токены
```

## Настройка

1. **Telegram-бот:** создай у @BotFather, вставь токен в `.env` (`TELEGRAM_BOT_TOKEN`).
   Добавь бота **админом** нужного канала.
2. **Канал:** впиши в `cities.yaml` → `telegram_channel` (`@username` или `-100...`).
3. **Погода (опц.):** ключ OpenWeather в `.env` (`OPENWEATHER_API_KEY`). Без него погода пропускается.

## Запуск

```bash
python run.py post currency          # опубликовать курс валют сейчас (тест)
python run.py post weather           # опубликовать погоду сейчас
python run.py serve                  # запустить планировщик (программа дня)
```

Без токена Telegram модуль всё равно построит пост и покажет его в консоли
(через заглушку MAX) — удобно проверять контент без реальной публикации.

## Как расширять

- **Новый контент-модуль:** класс в `content/`, наследник `ContentModule`, регистрация в `engine.py` → `MODULES`.
- **Новая платформа:** публикатор в `publishers/`, наследник `Publisher`, добавить в `engine.py` → `PUBLISHERS`.
- **Новый город:** блок в `cities.yaml`.
