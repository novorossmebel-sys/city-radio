# План: «Радио в мессенджере» — автоматизированное городское медиа для MAX и Telegram

**Дата:** 02.08.2026
**Продукт:** сеть локальных авто-каналов (по городам России): погода, курс валют, гороскоп, рецепты, здоровье/польза, юмор, местные новости и пробки — с ощущением «живого радио».
**Платформы:** MAX + Telegram (кросс-постинг из единого движка).
**MVP-город:** Новороссийск.
**Бюджет:** до 1 000 000 ₽.
**Формат:** максимально автоматизировано → полупассив после сборки.

---

## 0. Тезис и стратегия

- **Ставка на волну MAX** (85 млн DAU, рост на господдержке, ниша городских медиа там пока пустая) — заходим first-mover. Telegram — второй контур для дистрибуции и монетизации.
- **Единый контент-движок → публикатор → обе платформы.** Один пост генерится один раз и уходит и в MAX, и в Telegram.
- **Сначала 1 город (Новороссийск) как MVP**, движок city-agnostic → тиражирование = добавление конфига города.
- **Метрика go/no-go на MVP** до масштабирования (см. §9).

> ⚠️ Честная рамка: при полной автоматизации самый слабый и самый рискованный модуль — **местные новости**. Их нельзя тупо копировать (авторские права, фейки, репутация). Решение — агрегация только из белого списка местных СМИ с рерайтом и ссылкой на источник + жёсткий авто-фильтр (см. §4 и §8). ЧП/происшествия без верификации НЕ автопостим.

## 1. Контент-модули и источники данных

| Модуль | Источник (автомат) | Как формируется | Частота |
|---|---|---|---|
| Погода | API погоды (Яндекс.Погода / OpenWeather / Gismeteo) | шаблон-карточка + текст | 1–2/день (утро/вечер) |
| Курс валют | **API ЦБ РФ** (cbr.ru, бесплатно) | карточка ₽/$/€ + динамика | 1/день (после обновления ЦБ) |
| Пробки | Яндекс.Карты (уровень пробок по городу) | балл + комментарий | утро + вечер (часы пик) |
| Гороскоп | LLM-генерация (YandexGPT/Claude/GPT) | 12 знаков, 1 пост-дайджест | 1/день (вечер, на завтра) |
| Рецепт | LLM-генерация + сгенерированное фото | «рецепт на обед/ужин» | 1/день |
| Здоровье/польза | LLM-генерация с дисклеймером | короткий совет | 1/день |
| Юмор | LLM-генерация / лицензионная база | 1–2 поста | 1–2/день |
| Местные новости | **RSS/парсинг белого списка местных СМИ** → LLM-рерайт + ссылка на источник | дайджест 1–3 новости | 2–3/день |
| События/афиша (позже) | парсинг местных афиш | анонсы | по наличию |

**Итого ~8–12 постов/день** — но не «раз в 2 часа спамом», а по расписанию (см. §2).

## 2. Каденс = «программа дня» (ключ против отписок)

Как радиосетка — контент привязан ко времени, ощущается живым, не спамит:

- **07:00–09:00 (утро):** «Доброе утро, [город]» + погода на день + пробки + главная новость.
- **12:00–14:00 (день):** курс валют (после ЦБ) + новость + рецепт на обед.
- **17:00–19:00 (вечер):** вечерние пробки + дайджест новостей дня + польза/здоровье.
- **21:00–22:00 (ночь):** гороскоп на завтра + юмор + «итоги дня».

Экстренные локальные новости (проверенные) — вне сетки, по факту.

## 3. Техническая архитектура

```
[Планировщик/cron]
      │
      ▼
[Контент-движок] ── модули (погода, валюта, пробки, LLM-генерация, новости-агрегатор)
      │
      ▼
[LLM-слой] — генерация + рерайт новостей + авто-модерация/фильтр
      │
      ▼
[Рендер медиа] — брендированные карточки (HTML→image / Pillow)
      │
      ▼
[Очередь постов в БД] (PostgreSQL): город × платформа × время
      │
      ▼
[Публикатор] ──► Telegram Bot API (sendMessage/sendPhoto → канал)
             └──► MAX Bot/Channel API (→ канал)   ← подтвердить в Фазе 0
      │
      ▼
[Сбор статистики] — просмотры, ERR, отписки → дашборд
```

**Стек (ориентир):** Python (движок/боты), PostgreSQL, cron/Celery, VPS. LLM через API. Рендер карточек — headless-браузер или Pillow.
**Мультигород:** город = запись в конфиге (координаты для погоды, ID города для пробок, список RSS-СМИ, ID каналов TG/MAX). Движок один.

## 4. Местные новости — как автоматизировать безопасно

1. **Белый список источников** — только официальные/крупные местные СМИ и офиц. каналы (по каждому городу свой список RSS/страниц).
2. **LLM-рерайт**, не копипаст: пересказ своими словами + **обязательная ссылка на источник**.
3. **Авто-фильтр:** блок тем (политика, разжигание, непроверенные ЧП, мед./фин. советы, 18+), проверка на дубли.
4. **ЧП/происшествия** — не публикуем автоматически без второго источника (репутация + закон о фейках). На старте можно вынести в «ручной гейт» на 1 город; при масштабе — только из офиц. источников (МЧС/оперштаб).

## 5. Обе платформы — различия и учёт

| | Telegram | MAX |
|---|---|---|
| API публикации | Bot API — зрелый, простой | Bot/каналы есть; **точный API постинга подтвердить в Фазе 0** |
| Монетизация каналов | реклама-посевы, Telegram Ads, свой мини-апп | с 1 000 подписчиков, публичные каналы; расш. аналитика +40% к цене рекламы |
| Аудитория | зрелая, ниша занята локальными пабликами | ~85 млн DAU, ниша городских медиа **пустая** ← главный шанс |
| Мини-приложения | TWA (Telegram Web Apps) | Mini App + интеграция с VK |
| Рекламный кабинет | есть (Telegram Ads) | полноценного кабинета пока НЕТ (реклама через VK/посевы) |

**Вывод:** MAX — приоритет по росту (first-mover), Telegram — для быстрой сборки, дистрибуции и понятной монетизации. Один контент → оба канала.

## 6. Мини-приложение «выбери свой город» (фаза 2–3)

- Один продукт с выбором города вместо десятков пустых каналов.
- Пользователь выбирает город → персональная лента (погода/пробки/новости своего города) + подписка на уведомления.
- На MAX — нативно (Mini App + VK); в Telegram — TWA.
- Решает проблему «городов-призраков» и повышает удержание. Позже — местные сервисы (афиша, объявления).

## 7. Бюджет (CAPEX/OPEX, в рамках 1 млн)

**Разработка MVP (единоразово):**
| Статья | ₽ |
|---|---:|
| Разработка движка + публикатор (TG+MAX) + 1 город | 200 000–400 000 |
| Дизайн/брендинг + шаблоны карточек | 40 000–80 000 |
| Настройка источников/白 списка, тесты | 30 000–60 000 |
| **Итого разработка** | **~300 000–500 000** |

**Ежемесячно (OPEX):**
| Статья | ₽/мес |
|---|---:|
| VPS/хостинг | 2 000–5 000 |
| API (погода, пробки Яндекс, LLM-токены) | 5 000–20 000 |
| Поддержка/доработки | 10 000–30 000 |
| **Итого OPEX** | **~20 000–55 000/мес** |

**Разгон аудитории (главная статья, из оставшегося бюджета):**
- Посевы в местных пабликах, VK-таргет (MAX ↔ VK), кросс-промо, конкурсы/розыгрыши.
- **~300 000–500 000 ₽** на MVP-город + первые города. Твой бюджет здесь — редкое преимущество: конкуренты росли без денег.

> После сборки движка операционка минимальна (API + хостинг + присмотр) → это и есть полупассив. Основные деньги уходят не в «работу», а в разгон аудитории.

## 8. Юридические моменты (не игнорировать)

- **Каналы 10 000+ подписчиков** — регистрация в РКН.
- **Новости-агрегатор:** ссылки на источники, рерайт (не копия), только белый список → снизить риск статуса незарегистрированного СМИ/агрегатора.
- **Закон о фейках:** не публиковать непроверенные ЧП. Верификация/официальные источники.
- **Здоровье:** только общие советы + дисклеймер, без диагнозов/лечения.
- **Финансы:** курс валют = факт из ЦБ, без инвест-советов.
- **Контент:** генерировать (рецепты/юмор/картинки), а не копировать чужое.
- Оформить **ИП/самозанятость** под рекламные доходы.

## 9. Дорожная карта и метрика go/no-go

| Фаза | Срок | Что |
|---|---|---|
| **0. Валидация** | 1–2 нед | подтвердить API постинга MAX; собрать источники по Новороссийску; скан конкурентов на MAX/TG |
| **1. Сборка MVP** | 3–8 нед | движок + публикатор (TG+MAX) + Новороссийск на обеих; внутренний прогон |
| **2. Запуск + разгон** | 9–16 нед | публичный старт, платный набор аудитории, тюнинг каденса/контента по ERR, добить 1 000 подписчиков (порог монетизации MAX) |
| **3. Первые деньги** | мес 5–8 | первая местная реклама; отладка плейбука; старт мини-аппа «выбор города» |
| **4. Масштаб** | мес 8+ | тираж по городам (добавление конфигов); масштаб продаж/программатик |

**Go/no-go перед масштабированием (по итогам MVP-города):**
- Стоимость подписчика (CPF) и темп роста;
- Вовлечённость (ERR) и % отписок (каденс не спамит?);
- **Юнит-экономика 1 города:** покрывает ли он свои промо+OPEX и даёт ли прибыль?
- Есть ли первый платящий рекламодатель.
→ Если да — тиражируем по готовому плейбуку. Если нет — правим или стоп с малыми потерями.

## 10. Монетизация (по мере роста аудитории)

1. **Местная реклама** (посевы) — старт с домашнего города, где есть контакты; далее шаблонизировать продажи/самообслуживание.
2. **MAX-монетизация** каналов (с 1 000 подписчиков) + Telegram Ads.
3. **Партнёрки:** финансы (у блока «курс валют»), туризм (билеты/отели), доставка еды (у «рецепта»).
4. **Мини-апп:** местные сервисы, афиша, объявления, промо-места.
5. **Подписка/премиум** (без рекламы / расширенные локальные оповещения) — позже.

## 11. Ключевые риски → митигglobal

| Риск | Митигация |
|---|---|
| Автоконтент = нет моата | ядро = локальные новости/пробки/события; филлер — поддержка |
| Отписки от частоты | «программа дня» вместо спама раз в 2 ч |
| Ниша занята (Telegram) | приоритет MAX, где пусто |
| Холодный старт по городам | мини-апп «выбор города» + бюджет на разгон; сначала 1 город |
| Автопубликация фейков/ЧП | белый список + верификация + фильтр; ЧП не на автомате |
| Монетизация = продажи | старт с домашнего города; далее шаблон/самообслуживание/программатик |
| Незрелость API/кабинета MAX | Фаза 0 — проверка; Telegram как запасной контур |

## 12. Ближайшие действия (Фаза 0)

1. Подтвердить **возможность автопостинга в каналы MAX** (Bot/Channel API) — критично для «полной автоматизации».
2. Собрать по **Новороссийску**: список местных СМИ (RSS), ID города для пробок Яндекса, координаты для погоды.
3. **Скан конкурентов** на MAX и Telegram по Новороссийску (кто уже есть, размер, активность).
4. Найти **разработчика** (фриланс) под MVP-движок; согласовать смету.
5. Определить, кто закрывает **ручной гейт по ЧП** на старте (или строгий авто-режим только из офиц. источников).
