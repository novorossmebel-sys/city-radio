# Хендофф: подбор бизнеса под помещение / актив

**Дата:** 02.08.2026
**Локация:** Новороссийск
**Статус:** направление выбрано, идёт детализация

---

## 🎯 Цели

Найти жизнеспособный бизнес со стартовым бюджетом **до 1 000 000 ₽**, который:

- даёт устойчивый доход и разумную окупаемость;
- по формату — **услуги / онлайн / полупассивный** (минимум ежедневной рутины);
- изначально — под имеющееся помещение; в итоге допущен и бизнес без привязки к нему.

**Предпочтения владельца:**
- ✅ хочет: услуги, онлайн/цифровое, полупассивный формат;
- ❌ не хочет: активные «холодные» B2B-продажи (опт), маркетплейсы (как селлер), пищевое производство, кладовки/self-storage.

| Параметр | Значение |

## ⚠️ Проблемы (ключевые ограничения, вскрывшиеся по ходу)

1. **Помещение на закрытой территории завода** — клиенты физически не попадают внутрь. Это убивает все форматы «люди приходят к тебе» (студии, прачечная, зал, любые B2C-услуги на месте).
2. **Потолки 3 м** — не подходят под фотостудию/воздушные активности.
3. **Локальная конкуренция** — рядом уже работают фотостудии (не первый год).
4. **Поисковый спрос локально почти нулевой** — проверено Вордстатом по нескольким нишам (см. ниже). Онлайн-канал в масштабе города не кормит.
5. **B2B через поиск не работает** — заводы/кофейни не ищут поставщиков в Яндексе; это только активные продажи ногами.
6. **Набор ограничений почти не пересекается**: завод (нет трафика) + без активного B2B + без маркетплейсов + без еды + полупассив + услуги → поле почти пустое. Пришлось отпустить одно ограничение.

## 🛤️ Путь (что рассматривали и почему отклонили)

### 1. Раки (УЗВ) — стартовый запрос
Пересчитали дважды. При базовых вводных — капиталоёмко (~3,2 млн), окупаемость 5–6 лет. С учётом тепла + высоты потолков экономика улучшилась (окупаемость ~2,5–3 года), но направление оставили ради поиска чего-то легче. **Отклонено.**

### 2. Альтернативы под помещение
Грибы, микрозелень, дарк-китчен, фулфилмент, кофе. Сузили до **грибы (функциональные) vs обжарка кофе** → выбрали **кофе**.

### 3. Кофе-обжарка — глубокий разбор
Юнит-экономика, выбор ростера (5 кг — оптимум под цель ~1000 кг/мес), расчёт числа кофеен (~10–15 аккаунтов на ~550 кг/мес B2B), B2B-воронка.

**Проверка спроса Вордстатом (июль 2026):**

*Локально (Новороссийск):*
| Запрос | Запросов/мес |
|---|---:|
| кофе новороссийск (широкое) | 1 043 |
| «кофе новороссийск» (точная фраза) | 23 |
| купить кофе новороссийск | 55 |
| кофе в зернах новороссийск | 10 |
| доставка кофе новороссийск | 2 |
| свежеобжаренный кофе новороссийск | 0 |
| кофе оптом новороссийск | 0 |

*Федерально (Россия, точная фраза):*
| Запрос | Запросов/мес |
|---|---:|
| «кофе в зернах купить» | 5 636 |
| «кофе оптом» | 141 |
| «подписка на кофе» | 73 |
| «кофе по подписке» | 21 |

**Вывод по кофе:** локальный онлайн-спрос на покупку ≈ 0 (~3–5 тыс. ₽/мес потенциала); B2B через поиск мёртв (опт = только личные продажи); федеральный онлайн есть, но гиперконкуренция → **поиск не является мотором бизнеса**. Владелец охладел к кофе и к локальному опту. **Отклонено.**

### 4. Пивот «самые популярные запросы»
Разобрали ловушку: топ-запросы — это навигация (ВК, погода, маркетплейсы), бизнес на них не строится. Растущий кластер = **ИИ** (AI-агент, вайб-кодинг). Популярность ≠ возможность.

### 5. Уточнение критериев
Помещение — «плюс, но не догма»; формат — услуги + онлайн + полупассив; бюджет до 1 млн.

### 6. Идеи «услуги + онлайн + полупассив»
Самообслуживаемая фотостудия, прачечная самообслуживания, зал в аренду. → **Отклонены** после вскрытия факта про завод (нет трафика) + потолки + конкуренты.

### 7. Скрытые ниши для промзоны (B2B-соседи)
РВД (рукава высокого давления), заточка инструмента, порошковая покраска, ремонт электродвигателей, розлив техжидкостей, поддоны, 3D/ЧПУ.

### 8. 3D-печать — отдельный разбор
Рынок сбыта = **соседние предприятия** (запчасти, оснастка), не поиск. Требует навыка 3D-моделирования (свой или наёмный).
Проверка Вордстатом: локально ~50/мес (мираж), федерально мало (144–394), «печать оснастки» 6 344 = **штампы/печати, не 3D** (ложный сигнал). **Вывод:** 3D живёт только через активные B2B-продажи соседям → не «полупассив/онлайн». **Отклонено.**

### 9. Развилка ограничений
Осознали: условия почти не пересекаются. Владелец выбрал **отпустить привязку к помещению** → уход в чистый онлайн/цифровой бизнес.

> ⚠️ Важно при уходе от помещения: **сначала нейтрализовать аренду 55 000 ₽** (субаренда / выход из договора), иначе онлайн-проект стартует с −55к/мес.

### 10. Онлайн-направления
Купить готовый онлайн-актив с доходом / продуктизированная услуга на аутсорсе / ИИ-услуги для бизнеса / **контент-медиа на своей экспертизе**.

## ✅ Результат (текущее решение)

**Выбрано направление: Вариант 4 — контентно-медийный проект на основе личной экспертизы.**

Почему подходит:
- единственный формат, где актив **накапливается**: построил аудиторию → монетизация гибкая, маржа 80–90%, со временем — реальный полупассив;
- бюджет до 1 млн — **редкий козырь**: можно платно разгонять аудиторию или **купить готовый канал/проект** и достраивать (компрессия срока).

**Рабочая схема:**
- Платформа: **Telegram как денежный хаб** + воронка сверху (YouTube/VK Video/Дзен/Reels) + опц. сайт+SEO для «поисковых» тем.
- Монетизация (2–3 одновременно): реклама-посевы, партнёрки, **свой продукт** (консультации/курс/услуга), платная подписка/клуб.
- Критично: **ниша должна монетизироваться**. Топ-тиры: финансы/инвестиции, бизнес, недвижимость, IT, B2B, юр., маркетинг. Слабые: развлечения/юмор/новости.

**Честные ожидания:** длинная игра (6–18 мес до ощутимых денег), полупассив — после набора аудитории.

## ❓ Открытые вопросы (нужны, чтобы двигаться дальше)

1. **Тема/экспертиза** — о чём владелец может говорить/писать долго и предметно? (определяет всё: нишу, платформу, монетизацию, цифры)
2. **Формат** — текст (Telegram/сайт) / видео (YouTube/VK) / «за кадром» (без лица)?
3. **Публичность** — готов быть лицом проекта или анонимный проект?

---

## ➡️ Следующие шаги

1. Получить ответ по теме/экспертизе → оценить монетизируемость ниши (честно).
2. Выбрать платформу и модель монетизации под тему.
3. Составить план разгона аудитории на бюджет **или** подобрать готовый актив к покупке (+ чек-лист проверки актива от накрутки).
4. Прикинуть реальные цифры дохода и срок выхода на окупаемость.
5. Параллельно — решить судьбу помещения (субаренда / выход из аренды), чтобы убрать 55 000 ₽/мес.

## 🧭 Уроки процесса (принципы)

- **Проверяй спрос цифрами (Вордстат + 2ГИС + звонки клиентам) ДО вложений.**
- **Поиск — не всегда мотор бизнеса**: у многих ниш деньги в B2B/офлайн-отношениях, а не в поисковом трафике.
- **Ограничения локации решают**: закрытая территория завода отсекает целые классы бизнесов.
- **Раскрывай все вводные сразу** (завод, потолки, конкуренты) — экономит круги анализа.
- **Считай широкое vs точное («в кавычках») соответствие** в Вордстате — цифры отличаются в разы.
- **Смотри регион**: локальный и федеральный спрос — разные вселенные.
