### Найденные проблемы и решения

1. **Jina Reader (`r.jina.ai`, `s.jina.ai`) заблокирован** — отдаёт `451 Unavailable For Legal Reasons` прямо с Cloudflare, включая нейтральные тестовые адреса (`example.com`). Это гео-блокировка на стороне Jina по исходящему IP этой машины, **не блокировка локальной сети** (`google.com`, `novorab.ru` открываются напрямую и быстро). Прокси не настроен и вряд ли решит проблему без стороннего IP из незаблокированного региона.
   → **Решение:** не использовать Jina вообще, читать через `mcporter call web-reader.fetch_url_local url="..."` (или `fetch_url` с `preferJina: false`).

2. **npm-шим `mcp-web-reader` не работает под git-bash на Windows** — при прямом запуске интерпретирует JS-файл как шелл-скрипт (`import: command not found`).
   → **Решение:** зарегистрировали MCP-сервер в mcporter напрямую через `node`, в обход шима:
   ```
   mcporter config add web-reader --command node --arg "C:\Users\Profi\AppData\Roaming\npm\node_modules\mcp-web-reader\dist\index.js" --scope home
   ```

3. **Postinstall-скрипт `mcp-web-reader` (загрузка Chromium ~100–200 МБ для режима `fetch_url_with_browser`) пропущен** политикой `npm allow-scripts`. Не критично — локальный парсер и так работает для наших задач; если понадобится браузерный режим (сайты с Cloudflare/капчей), нужно доустановить отдельно: `npx playwright install chromium`.

4. **Прямой доступ заблокирован/недоступен в этой сети** (не инструмент, а сетевые ограничения окружения — фиксируем для будущих сессий, чтобы не тратить время на повторную диагностику):
   - Яндекс-поиск (`yandex.ru/search`) — капча (`showcaptcha`).
   - `tgstat.ru`, `2gis.ru` — 403 (бот-защита).
   - `t.me` (веб-превью каналов), `youtube.com`, `bbc.com` — таймаут на уровне TLS (аналогично блокировке `api.telegram.org`, описанной в `docs/handoff.md` от 08.08.2026).
   - Для точечной проверки таких источников пользователь предложил присылать скриншоты вручную — использовать этот путь при необходимости.

## 3. Выбор рубрик контента (в процессе)

### Логика работы, которую нужно реализовать (согласована с пользователем, **пока не закодирована**)

1. Найти новость (по источникам, которые ещё предстоit согласовать по каждой рубрике).
2. Проверить (верификация, см. юридические ограничения в `docs/plan_city_radio.md` §4, §8 — не публиковать непроверенные ЧП).
3. Переписать своими словами, **не меняя сути**.
4. Отправить пользователю на модерацию.
5. Пользователь вносит правки (если нужно).
6. Публикация в **MAX**.
7. Пауза **30–40 секунд**.
8. Публикация в **Telegram**.

### Проделанное исследование

Проанализированы (в пределах доступности сети, см. §2.4): популярные Telegram-каналы Новороссийска (ЧП Новороссийск, Супер Новости Новороссийска), VK (`news_of_novorossiysk`), Instagram (`gorod_novorossiysk` — 160K, `love_nvrsk` — 34K, `nespeshnik` — еда/кафе, `bloknot_novorossiysk`), YouTube (Novoross TV, НовороссияТВ, ФК «Черноморец»), афиша (Яндекс.Афиша — концерты/театр/кино с расписанием). Для ориентира на рубрикацию сверились со структурой BBC News, Lenta.ru, Mash и Baza.

Собраны и объединены **3 варианта списков рубрик** (общий/национальный формат, черновик по локальным соцсетям, гиперлокальный под Новороссийск) — итого **48 позиций** в 4 партиях.

### Инструмент выбора

Опубликован интерактивный чек-лист **«Манифест рубрик»**:
https://claude.ai/code/artifact/a7728f83-a56c-4b26-a30a-dcf3e823ca2e

Функционал: чекбокс на каждую рубрику + поле комментария справа (источник + мысли по наполнению), живой счётчик отмеченных, кнопка экспорта списка в текст (для вставки в чат), сохранение состояния в браузере.

**Статус:** ждём от пользователя финальный отмеченный список с комментариями по источникам.

## 5. Известные ошибки/риски на заметку

- MAX-паблишер не проверен на живом токене (см. п.6 выше) — при первом реальном посте вероятны 401/403/404, нужно будет поправить константы в `publishers/max.py`.
- Текущий `engine.py` не умеет ни очередь модерации, ни паузу между площадками — это архитектурное изменение, а не косметика; планировать отдельно.
- Все инструменты чтения интернета (agent-reach/OpenCLI/web-reader) установлены **на уровне пользователя Windows**, не в репозитории — при работе с этим проектом в другом окружении/на другой машине их нужно ставить заново по этой инструкции.
